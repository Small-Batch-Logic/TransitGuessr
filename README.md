# TransitGuessr

A web game about knowing your city's transit system — not just the lines, but where the stations actually live.

You get a Street View panorama of a station entrance. Place a pin on the map to guess where it is. Recognize the streetscape, the neighborhood, the transit context.

- Toronto TTC, Worldwide, and city-specific system modes
- Daily Challenge with globally consistent rounds
- Hard mode locks movement; Easy allows limited exploration
- Five rounds, 60 seconds each, with local high-score tracking
- Share your results at the end screen

Built with vanilla JS and Leaflet. Station panoramas served via Google Street View.
